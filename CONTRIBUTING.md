# Contributing

Contributions to this repository are welcome through GitHub pull requests.

Unless you explicitly state otherwise in writing, any contribution you
intentionally submit for inclusion in this project is licensed under the
Apache License, Version 2.0, in accordance with section 5 of that license. By
submitting, you represent that you have the right to provide the contribution
on those terms.

Do not submit third-party icon archives, extracted icon collections, generated
icon packs, or artwork whose redistribution rights you cannot establish.
Provider fixtures must be small, synthetic, and created for testing.

Changes affecting source selection, provenance, rights evidence, notices, or
pack serialization must include tests and corresponding documentation.
